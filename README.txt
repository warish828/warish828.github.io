# Warish — Portfolio

A simple, professional, responsive portfolio website.

## Files
- index.html
- style.css
- script.js

## Run in Termux
From this folder:

    python -m http.server 8080

Then open:
    http://127.0.0.1:8080

## Customize
Edit `index.html` to add your GitHub, Instagram, real projects, or additional information.
